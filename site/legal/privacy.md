## 2. 브라우저에만 저장하는 값

| 이름 | 값 | 용도 | 지우는 방법 |
|---|---|---|---|
| `radar.dirbrief.open` | `1` 또는 `0` | 홈의 "전체 브리프 읽기"를 펼쳐 두었는지 기억 | 브라우저의 사이트 데이터 삭제 |

이 값은 방문자의 브라우저(localStorage)에만 있고 어디로도 보내지 않습니다.

## 3. 페이지를 열 때 브라우저가 요청을 보내는 곳

페이지를 열면 브라우저가 아래 사업자에게 요청을 보냅니다. 이때 각 사업자는 IP 주소와 브라우저 정보를 받을 수 있고, 그 처리는 각 사업자의 방침을 따릅니다.

| 사업자 | 무엇을 받아오나 | 방침 |
|---|---|---|
| GitHub (GitHub Pages) | 이 사이트의 페이지와 자료. GitHub 문서에 따르면 Pages 사이트 방문 시 방문자 IP 주소가 보안 목적으로 기록·저장됩니다 | https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement |
| Google (Google Fonts) | 글꼴 IBM Plex Sans KR | https://policies.google.com/privacy |
| Cloudflare (cdnjs) | 브리프 문서를 화면에 그리는 스크립트 marked | https://www.cloudflare.com/privacypolicy/ |

시그널의 출처 링크를 누르면 그 사이트로 이동하며, 그 뒤는 해당 사이트의 방침을 따릅니다.
